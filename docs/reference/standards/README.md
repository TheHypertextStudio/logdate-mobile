# Development standards

The standards that apply to every change to LogDate. Each one lives in its own document, and the
document is the authority on its topic.

- [App lock](app-lock.md) covers how the lock gates restored and local journals, and what happens when authentication is missing, unavailable or unknown.
- [Commit message standards](commit-messages.md) explains how to write a commit title, body and trailers, how to choose between `feat`, `fix` and `chore`, and which rules the hooks enforce.
- [Commit scopes](commit-scopes.md) lists every registered commit scope with what it covers.
- [Entrypoint structure](entrypoint-structure.md) describes how top-level entrypoints stay small and the detekt limits that enforce it.
- [Git guidelines](git-guidelines.md) covers staging, commit sequencing, and landing a branch through a pull request.
- [Media quality checklist](media-quality-checklist.md) lists the standing rules for every image and video pipeline.
- [Settings state](settings-state.md) describes where loading and feedback state belong on a settings page.
- [Settings UI](settings-ui.md) describes how settings pages compose their rows and sections.
